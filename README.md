# Introduction 
A simple web application to manage expances for small groups

# Getting Started

In API and WEB project you will find a README file. Follow the instruction to build and run the solution 

# Features
- Authentication
- User management
- Expences management

# Tech Stack
 - **API**: .NET 9.0
 - **WEB**: React (vite)
 - **Database**: support for the following: Sqlite, InMemoryDatabase, SQL
